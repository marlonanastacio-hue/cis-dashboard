Weekly targets

Each week cell shows the actual % of that week's assigned devices that are done, with done / assigned and how many are left underneath. A device is deducted automatically as soon as a hardening report for it is on file (uploaded by anyone), or when it is removed in Manage targets. Red = week is over and devices are overdue; amber = this week; ✓ = 100%, nothing left. ↑ = reports uploaded that week. "Uploaded" credits each technician's own reports on any device.
